# Sitewise cadastral S — concept 01

This is a review study. The live application and landing logo are unchanged.

## Direction

Keep the recognisable S and its two matching strokes. Replace the curved elbows
with straight boundaries, a chamfered outer corner and a stepped inner return.
The shape borrows the language of parcel boundaries and access handles visible
in the cadastral study; it is an abstract brand construction, not a traced legal
lot or a claim about the demonstration property's boundaries.

The second form is exactly the first rotated 180 degrees around (60, 60). A
single SVG path is reused with `<use>`, so the two forms cannot drift apart in
later edits. The continuous negative space reads as access between the forms.

## Review

Open `index.html`. It includes the current mark beside the concept, a geometric
construction diagram, light and true near-black applications, and actual 16,
24 and 48 CSS-pixel scale checks. The current comparison uses the live PNG
silhouette with a CSS mask so the comparison is about form rather than colour.

Use one colour in the final mark. Air/Citron differentiation appears only in the
construction drawing to explain the two identical parts. The wordmark is a
placement study using the existing Satoshi Bold font, not a new type design.

## Recommendation

Develop this as a restrained evolution of the current S. It connects the brand
to the cadastral composition and makes the two-part construction more explicit.
Before replacing the live logo, review the small-size silhouette and decide
whether the deliberately angular access return is the desired brand character.
