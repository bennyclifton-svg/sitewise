# Static opening hero — blue ground / chalk building

Historical first checkpoint. The active page now uses the lower perspective
study generated by `build_perspective_hero.py` and the expanded shared plan
from `export_perspective_context.py`. Running the older commands below recreates
the original isometric study and its original public plan.

First still checkpoint for the approved approximately 55/45 landing split.
The registered full development sits on a level blue parcel field at left; the matching
plan is transparent vector linework for a white right-hand panel. Animation is deferred.

## Delivery assets

- `frontend/public/landing-assets/coordination/sitewise-hero-isometric.webp` — 1200 × 1320; 47,774 bytes.
- `frontend/public/landing-assets/coordination/sitewise-hero-plan.svg` — matched lot, neighbours and projected roof outlines.
- `frontend/public/landing-assets/coordination/sitewise-hero-credits.json` — provided source attribution metadata.
- `Landing/model/coordination/19-static-hero-isometric.png` — original Blender render.
- `Landing/model/coordination/sitewise-static-hero.blend` — editable derived scene.
- `Landing/model/coordination/static-hero-manifest.json` — placement, camera, source and art-direction record.

The plan viewBox is `-52 -32 104 64`. With `object-fit: contain`, the entire selected
parcel (Y ±22) remains visible on shorter desktop panels; outer context lines may crop.
The older `20-static-hero-plan-preview.png` records the initial wider vertical map extent;
use the SVG for the final page, not that audit preview.

## Reproduce from the repository root

```powershell
& 'C:/Program Files/Blender Foundation/Blender 5.1/blender.exe' --background --python Landing/model/coordination/build_static_hero.py
python Landing/model/coordination/export_static_hero.py
```

To refresh only the vector plan and metadata, append `-- --plan-only` to the Blender
command. This skips the still render and does not overwrite the derived Blender scene.
The WebP exporter uses the already available Pillow installation and only converts format.

## Review and provenance

- Render inspected for full-development composition, readable parcel, blue/chalk separation,
  shadows and restrained warm glazing; source building transforms are checked unchanged.
- Plan inspected against the isometric: same parcel and development arrangement, with
  34 projected roof faces and 59 outline edges. No drawing triangulation is intentionally shown.
- Original GLBs and the earlier siting scene remain unchanged. There is no exposed structural
  overlay; reinforced-concrete columns and slabs remain the active future modelling direction.
- The parcel is an illustrative reconstruction from the supplied cadastral artwork, without
  verified survey coordinates, utility connections, legal boundaries or setback compliance.
