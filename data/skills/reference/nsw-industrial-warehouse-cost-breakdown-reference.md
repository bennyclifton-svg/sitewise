# NSW Industrial Warehouse Cost Breakdown Reference

This is a practice-level taxonomy reference for early NSW industrial
warehouse and logistics cost plans. It covers the `warehouse` /
`logistics_ecommerce` Class 7b practice shape only: the groups and
construction breakdown families a Create Cost Plan draft should use to
structure the document. It is not a rate pack, not active-project evidence,
a market-rate source, a project budget, a tender recommendation, or a
source-of-truth cost plan.

Create Cost Plan workflows may cite this reference as practice guidance for
industrial warehouse projects. They must not treat this reference as
evidence for any active project and must not borrow it for residential,
commercial fit-out, or other non-industrial building classes.

## Workbook-Ready Groups

Use these groups to shape Markdown cost plans that can later map into the
practice workbook structure:

- Fees and charges
- Consultants
- Construction
- Contingency / allowances

## Construction Taxonomy

The default NSW industrial warehouse construction breakdown should remain
project-specific but normally consider these item families:

| Family | Typical cost item labels |
| --- | --- |
| Preliminaries | Site establishment, authority fees, statutory levies, temporary services, site amenities, supervision, insurances |
| Siteworks and earthworks | Site clearing, demolition, bulk earthworks, cut/fill, retention systems, service lead-ins, temporary protection |
| Substructure and slabs | Footings, pad and strip footings, ground slab (including superflat/hardener finish where specified), reinforcement, concrete pumping |
| Structural steel and frame | Portal frame, purlins, girts, bracing, craneage, fabrication and erection allowances |
| Roof cladding and envelope | Roof sheeting, wall cladding, insulation blanket, flashings, skylights, gutters and downpipes |
| Dock hardstand and yard | Loading dock levellers, dock doors and canopies, hardstand pavement, yard drainage, bollards and line marking |
| Office fitout (ancillary) | Ancillary office/amenities fitout, partitions, ceilings, floor coverings, kitchenette and amenities fixtures |
| Building services | Electrical services, mechanical/HVAC (office only unless specified), fire services, hydraulic services, communications |
| External works and stormwater | Car parking, driveways, fencing and gates, landscaping, stormwater detention and drainage |
| Specialist systems (gap) | Racking, cool rooms, dock automation, conveyor or MHE-related building works — flag as a gap when scope is undefined |

## Fees and Consultants Guidance

- Do not frame fees or consultants using BASIX or residential kitchen/joinery
  language — this taxonomy is not a residential cost plan.
- Frame planning approval evidence around DA/CC or CDC pathway status, not a
  residential complying-development assumption.
- Typical industrial consultants beyond the residential set include a fire
  engineer and a civil engineer; include them only where project evidence
  supports the allowance.

## Use Rules

- Treat the list as a starting taxonomy, not a mandatory schedule.
- Use project-specific `Cost Items` labels in the cost plan.
- Keep exact approved `Cost Items` text stable because later invoices and variations
  will use that text as a workbook lookup identity.
- Keep GST basis explicit. Create Cost Plan v1 uses ex-GST figures.
- Calculate construction contingency on construction cost only.
- Prefer lump-sum lines where quantity and rate detail would create fake precision.
- Disclose plainly when no market-rate pack exists for a family instead of
  inventing a rate.

## Boundary

This reference intentionally excludes:

- market rates, benchmark $/m² figures, or supplier pricing for any family;
- current market-rate advice;
- specialist systems detail (racking, cool rooms, dock automation) beyond
  flagging them as a scope gap;
- any instruction to read another project folder as evidence.
