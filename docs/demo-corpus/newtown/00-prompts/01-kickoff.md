# Prompt 1 — kick-off

Paste into the chat composer of a brand-new, empty project. Nothing else set up. Type it at
human speed, roughness intact.

---

> Rear extension and second storey addition to a semi in Newtown. Master bedroom and a
> parents' retreat upstairs, new kitchen opening onto an open plan living dining. Heritage
> conservation area. Budget around $750k.

---

## What it should resolve to

| Field | Expected |
|---|---|
| Building class | Residential |
| Subclass | House (Class 1a) |
| Work type | **Extension / addition** |
| State | NSW |
| Scale band | S · $250k–$2m |
| Budget | $750,000 |
| Storeys | 2 |
| Bedrooms | *not supplied — should stay empty* |
| GFA | *not supplied — should stay empty* |
| Planning | DA |
| Site address | Newtown NSW *(street not supplied)* |

## What it should **not** do

- Invent a GFA, a bedroom count, or a street number. The prompt gives none of them.
- Resolve work type to `new`. It is an addition to an existing dwelling.
- Name an Architect as appointed. Nobody has been engaged yet.

## The frame worth capturing

The empty fields. `GFA` and `Bedrooms` greyed out, holding, because one sentence cannot
support them. Everything the animation argues about evidence discipline starts here.

## Initial accommodation schedule

Five rows is the right answer from this prompt — the four spaces named, and nothing else.
The plunge pool arrives in prompt 2 as an owner correction.

| Space | Level | Area | Characteristics | Status |
|---|---|---|---|---|
| Master Bedroom | First | TBC | TBC | New |
| Parents' Retreat | First | TBC | TBC | New |
| Kitchen | Ground | TBC | TBC | New |
| Living / Dining | Ground | TBC | open plan | New |

If the agent invents a study, an ensuite or a laundry at this point, that is a defect —
none of them are in the prompt. They arrive with the brief, which is the whole point of
step 6.
