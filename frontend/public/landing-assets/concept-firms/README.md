# Illustrative firm identities

Eight original fictional concept identities for the landing-page design. These are not clients, partners, endorsements or verified trading names. The visible strip discloses their fictional status.

Visual research references: https://www.hassellstudio.com/studio/why-hassell , https://www.multiplex.global/ , https://www.turnerandtownsend.com/en-us/ . No reference logos were copied.

SVG artwork uses neutral grey, restrained geometric symbols and a mix of serif and sans-serif wordmarks. The strip uses 192 x 58 display boxes, 240 px slots and a 48-second seamless pass. Mobile uses 190 px slots. It is in normal document flow, pauses when hidden or offscreen, supports manual pause and respects reduced motion.

The desktop hero reserves 130 px for the logo strip in the initial viewport. The logo animation moves right to left at a linear speed and does not pause on hover/focus; the explicit pause button and reduced-motion preference remain available. Mouse-wheel zoom is disabled on the model so scrolling passes through to the document. Daylight controls use a compact neutral slider without the sun-path caption.

Latest revision: transparent strip lifted 20 px; pause/resume buttons removed; concise visible disclosure reads Concept logos. The project-demo pause/resume controller excludes sw-firm-drift so it cannot freeze the independently managed strip. Reduced motion and offscreen/document visibility pausing remain supported.
