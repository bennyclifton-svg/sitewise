# Nunito

Source: https://github.com/google/fonts/tree/main/ofl/nunito

Retrieved 2026-09-09. Nunito is distributed under the SIL Open Font License;
see OFL.txt. The original variable TTF is retained. Nunito-Latin.woff2 is a
FontTools subset of U+0020–U+00FF with the variable weight axis retained.

The landing hero uses weight 650 for rounded terminals and a softer silhouette.
