A real planning drawing, read by SiteWise and built into the plan beside it. The register marks which documents the open artefact actually used, and every statement keeps the source it came from — so checking the ones that matter is cheap, and you can leave the rest alone.

Where the judgement actually happens.

Two kinds of judgement run this project. Yours, over what the document should say. The model's, over what a sentence means. Everything between them — finding, filtering, counting, checking — is ordinary software, and it runs the same way every time.
